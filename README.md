# Pelotense Temp File

Sistema de envio temporário de arquivos com link público, expiração programada e proteção por senha.

## LGPD - Proteção de Dados

- Arquivos são armazenados temporariamente e excluídos automaticamente após o prazo definido pelo administrador.
- O administrador pode excluir arquivos a qualquer momento pelo painel.
- Não coletamos dados pessoais dos visitantes que baixam arquivos via link público.
- Para exercer direitos LGPD (acesso, correção, exclusão), entre em contato: admin@ahoradosul.com.br
